# 🎵 StudioManager

> Система учёта занятий частной музыкальной / художественной студии.

Приложение автоматизирует ведение журнала индивидуальных и групповых
занятий, расписание кабинетов, учёт баланса учеников, расчёт и выплату
комиссионных преподавателям.

---

## 🎯 Возможности

- 👥 **Учёт учеников** — карточка, баланс, история занятий, платежей
- 🎓 **Учёт преподавателей** — ставка, процент комиссии
- 📚 **Журнал занятий** — индивидуальные и групповые, статусы (planned / done / cancelled / paid)
- 📅 **Расписание кабинетов** — занятость по датам, проверка конфликтов
- 💰 **Финансы** — пополнение баланса, списание за занятия, список должников
- 📊 **Отчёты** — сводка по доходам, экспорт в CSV и JSON
- 🔐 **Авторизация** — 3 роли: администратор, преподаватель, ученик

---

## 🔐 Роли и доступ

| Роль | Логин | Пароль | Доступ |
|---|---|---|---|
| **Администратор** | `admin` | `admin123` | Все 6 разделов |
| **Преподаватель** | `teacher` | `teacher123` | Расписание, Отчёты |
| **Ученик** | `student` | `student123` | Расписание |

> 💡 Для быстрого входа — кликните на строку тестового аккаунта в окне входа.
